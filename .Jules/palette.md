## 2026-06-06 - Focus and Screen Reader Context for Icon-Only Buttons
**Learning:** Icon-only interactive elements lacking ARIA labels, titles, and `focus-visible` states present accessibility challenges, especially when `focus:outline-none` removes default outlines. Adding French-localized attributes (`aria-label="Se déconnecter"`, `title="Se déconnecter"`) ensures both screen reader support and mouse hover tooltips, while `focus-visible` fallbacks restore critical keyboard navigation visibility against dark backgrounds.
**Action:** Always pair `focus:outline-none` with a comprehensive `focus-visible` fallback (e.g., `focus-visible:ring-2 focus-visible:ring-white/30 focus-visible:ring-offset-1 focus-visible:ring-offset-black`) and add descriptive `aria-label` and `title` attributes matching the application's localization for all icon-only buttons.
