## 2023-10-27 - Hidden Text and Hover-only Actions
**Learning:** In complex toolbars (like the OmniBar), some text labels are visually hidden on smaller screens (`hidden sm:inline`), and some destructive actions (like removing an attachment) are hidden until hover (`opacity-0 group-hover:opacity-100`). This causes screen readers to miss the action description entirely if `aria-label` is not used, and keyboard users to navigate blindly without focus-visible styles.
**Action:** When using hidden-on-hover patterns (`group-hover:opacity-100`), always pair them with keyboard focus visibility classes (e.g., `focus:opacity-100 focus-visible:ring-2`) and provide an `aria-label`. Similarly, buttons with text labels hidden on smaller viewports must have an `aria-label` describing the full action to maintain mobile accessibility.
