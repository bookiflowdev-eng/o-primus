## 2026-05-23 - Added ARIA Label and Focus Styles to AppShell LogOut Button\n**Learning:** The application's UI is localized in French. Accessibility labels (like `aria-label` and `title`) should match the surrounding context (e.g., using 'Se déconnecter' instead of 'Log out'). Icon-only buttons frequently miss explicit context and focus rings; `focus-visible:ring-2` paired with offset classes ensures visibility against dark themes.\n**Action:** Always check the language context of the surrounding UI before adding accessibility labels. Pair `aria-label` and `title` for icon-only buttons, and ensure a robust `focus-visible` style is applied to match the global design system.
