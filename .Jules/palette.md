## 2024-05-21 - Icon-Only Button Accessibility Pattern
**Learning:** Icon-only interactive elements (like LogOut buttons) without `aria-label` and `title` are inaccessible to screen reader users and pointer-device users who rely on tooltips for context. Additionally, when using `focus:outline-none`, the lack of a `focus-visible` fallback severely impairs keyboard navigation visibility, especially on dark backgrounds.
**Action:** Always include `aria-label` and `title` attributes on icon-only buttons. Whenever `focus:outline-none` is applied to remove default browser outlines, simultaneously implement a robust `focus-visible` ring pattern (e.g., `focus-visible:ring-2 focus-visible:ring-white/30 focus-visible:ring-offset-1 focus-visible:ring-offset-black`) to ensure keyboard users can track their focus state clearly.
