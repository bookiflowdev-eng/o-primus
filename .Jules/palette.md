## 2026-07-29 - Keyboard Focus Rings & Icon Accessibility
**Learning:** In the O-Primus dark UI, many interactive elements in the sidebar rely on `focus:outline-none` which hides the default focus indicator for keyboard users. Additionally, icon-only action buttons (like LogOut) often lack descriptive context for screen readers and tooltips for pointer users.
**Action:** When styling interactive elements, always pair `focus:outline-none` with explicit `focus-visible:ring-2` styles. Use `focus-visible:ring-offset-2` combined with a matching background color offset (e.g., `focus-visible:ring-offset-[#030303]`) to ensure the ring is visible against the dark theme. Always add localized `aria-label` and `title` to icon-only buttons, and mark the decorative SVG with `aria-hidden="true"`.
