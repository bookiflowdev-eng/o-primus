## 2024-05-15 - Specific ring-offset matching for focus-visible in dark themes and French localization for aria-label
**Learning:** For interactive elements placed in dark sections (like `#050505` main sidebar or `#030303` sidebar footer), `focus-visible` outlines must explicitly use matching `ring-offset-[color]` to perfectly blend with the background and avoid clipping or mismatched focus rings. Additionally, the applications accessibility labels (such as `aria-label` and `title`) are primarily localized in French, so enhancements should match this localization (e.g. `aria-label="Se déconnecter"`).
**Action:** Always verify the surrounding container background color via CSS utilities before applying `focus-visible` offset classes, and use French localization for accessibility labels.
