## 2024-05-18 - A11y and Focus States for Icon-only Buttons on Dark UI
**Learning:** In a dark-themed UI (like O-Primus), icon-only interactive elements lacking focus states are practically invisible to keyboard navigators. Furthermore, applying standard accessible labels requires maintaining localized context (e.g., using "Se déconnecter" instead of "Logout"). The combination of `aria-label`, `title`, and highly contrasting `focus-visible` styles with offsets ensures both screen readers and sighted keyboard users can interact with confidence.
**Action:** Always pair `focus:outline-none` with explicit `focus-visible` rings (e.g., `focus-visible:ring-2 focus-visible:ring-white/30 focus-visible:ring-offset-1 focus-visible:ring-offset-black`). Ensure icon-only buttons include `aria-label` and `title` attributes matching the application's French localization.
