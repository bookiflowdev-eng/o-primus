## 2024-07-18 - Focus Visibility on Dark Backgrounds and Localized Icon Buttons
**Learning:** In highly customized dark themes (like `#000000`, `#030303`, or `#050505` backgrounds used in AppShell and Navbar), standard `focus-visible` rings often blend in or lack contrast. Using an explicit `focus-visible:ring-offset-2` with a color that matches the specific element's container background (e.g., `focus-visible:ring-offset-[#030303]`) ensures the focus ring is always legible. Additionally, screen readers need explicitly localized accessibility labels (e.g., `aria-label="Se déconnecter"`) for icon-only buttons, as generic english labels break the localized user experience.
**Action:** Always pair `focus-visible:ring-2 focus-visible:ring-white/50` with `focus-visible:ring-offset-2 focus-visible:ring-offset-[CONTAINER_BG_COLOR]` for interactive elements in dark themes. Ensure icon-only actions have `aria-label` and `title` translated to the app's primary language (French in this case), and mark the inner SVGs as `aria-hidden="true"`.
