## 2024-05-19 - Keyboard Navigation and Focus States in Dark UI
**Learning:** Adding `focus:outline-none` for aesthetic purposes is common, but it completely breaks keyboard accessibility if not replaced with a custom focus ring. In this dark UI environment, a stark contrast is required for visibility; standard rings blend in. The icon-only buttons (like LogOut) were missing both ARIA labels for screen readers and visible focus states for keyboard users.
**Action:** When working on UI enhancements in this project, explicitly verify that interactive elements lacking visible text have `aria-label` (localized to French) and decorative icons are hidden (`aria-hidden="true"`). Always ensure `focus-visible` classes define both the ring color (e.g., `ring-white/50`) AND a matching offset color (`ring-offset-[#030303]`) to ensure the focus state is visually distinct against the custom background.
