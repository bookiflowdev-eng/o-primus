## 2024-03-24 - Accessibility of icon-only buttons in dark mode components
**Learning:** For interactive elements placed in dark sections (like the AppShell sidebar footer with `bg-[#030303]`), `focus-visible` outlines must explicitly use `ring-offset-[#030303]` to perfectly match the background. Furthermore, icon-only interactive elements must explicitly include `aria-label` and `title` attributes for context, and internal SVG icons must be explicitly marked with `aria-hidden="true"` to prevent screen readers from redundantly announcing or misinterpreting them.
**Action:** When implementing hidden-on-hover UI patterns or any icon-only interactive buttons, always ensure that proper aria attributes and `focus-visible` ring offsets that match the background color perfectly are used.
