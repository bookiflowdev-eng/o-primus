## 2024-07-09 - Accessible Focus Rings on Hover UI
**Learning:** Hidden-on-hover UI patterns in this app (e.g., opacity-0 group-hover:opacity-100) often completely miss keyboard focus visibility unless paired with focus:opacity-100 or a reliable focus ring.
**Action:** Always ensure that interactive elements that are hidden by default include focus states so they become visible to keyboard users when navigating.
