## 2024-05-15 - AppShell LogOut Button Accessibility
**Learning:** For interactive elements placed in the dark `AppShell` sidebar footer, `focus-visible` outlines must explicitly use `ring-offset-[#030303]` to perfectly match the `bg-[#030303]` background and avoid clipping or mismatched focus rings. Additionally, SVG icons inside these icon-only buttons need `aria-hidden="true"`, as screen readers should rely on the added `aria-label` instead of attempting to interpret the SVG.
**Action:** When adding keyboard focus styles to elements on specific non-standard backgrounds (like `#030303`), ensure the offset color is explicitly set rather than relying on default transparent/white backgrounds. Always add `aria-hidden="true"` to pure decorative icons inside labeled buttons.
