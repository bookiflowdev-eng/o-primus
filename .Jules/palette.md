## 2026-08-27 - Visible Focus Rings on Dark Themes & Icon Button Accessibility
**Learning:** When aggressively removing default outlines with `focus:outline-none` in dark themes, keyboard navigation becomes impossible to see. Using `focus-visible:ring-2` requires `ring-offset` classes that match the background (e.g., `focus-visible:ring-offset-black`) to ensure the focus ring remains visually distinct. Additionally, icon-only buttons need explicit `aria-label` and `title` attributes, and the internal decorative SVGs must have `aria-hidden="true"` to prevent screen reader redundancy.
**Action:** Always pair `focus:outline-none` with a high-contrast `focus-visible` fallback that specifies the appropriate ring offset color for the surrounding background, and ensure all icon-only interactive elements follow strict ARIA labeling and hiding rules.
