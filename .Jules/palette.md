## 2025-02-12 - Accessible Dark Mode Focus and Icon Labels
**Learning:** Dark mode interfaces frequently hide native focus outlines or have insufficient contrast. Existing `focus:outline-none` styles remove default keyboard focus visibility, causing accessibility failures for keyboard navigation. Additionally, standalone icons in buttons create confusing or silent screen reader experiences.
**Action:** When working on elements with `focus:outline-none`, particularly in dark mode environments, always pair them with robust custom focus rings (`focus-visible:ring-2 focus-visible:ring-offset-2`) matched specifically to the background (`ring-offset-[#030303]` or `ring-offset-black`). For icon-only buttons, consistently apply descriptive `aria-label` and `title` attributes, ensuring the child SVG icons themselves are set to `aria-hidden="true"`.
