## 2024-05-24 - Interactive Elements in Dark Panels Need Specific Focus Offsets
**Learning:** In the `AppShell`, sidebar elements inherit very specific dark backgrounds (`#050505` for main sidebar, `#030303` for the footer). Generic `focus-visible:ring-offset-background` doesn't work correctly here because the application root background is `#000000`. Using `focus:outline-none` completely hid focus states for keyboard users.
**Action:** When adding `focus-visible` to interactive elements placed in specific dark panels (like `aside` or `footer`), explicitly use `focus-visible:ring-offset-[#XXXXXX]` matching the parent's exact background color to ensure the focus ring isn't clipped or miscolored. Always verify the parent's background color in the source code rather than assuming it's the default background.
