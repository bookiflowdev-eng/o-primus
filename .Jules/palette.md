## 2026-09-25 - [AppShell LogOut Button Accessibility]
**Learning:** Interactive elements placed in the dark AppShell sidebar footer require explicit `focus-visible:ring-offset-[#030303]` to seamlessly match the `bg-[#030303]` background without clipping or mismatched rings. Furthermore, all internal decorative SVGs for icon-only buttons must be explicitly marked `aria-hidden="true"` to prevent screen reader redundancy when an `aria-label` is added to the parent button. The UI is localized in French.
**Action:** When applying keyboard accessibility (focus) styles to icon-only buttons in complex dark-mode layouts, precisely sample and apply the local background color as the ring offset. Always include `aria-hidden="true"` on child SVGs when the parent button provides the accessible name.
