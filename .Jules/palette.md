## 2026-06-22 - Focus Outline Accessibility in Dark Themes
**Learning:** When building custom interactive elements (like icon-only avatars or minimal buttons) on dark themes, using `focus:outline-none` to remove default browser rings completely breaks keyboard accessibility unless explicitly paired with a `focus-visible` fallback. Because default outlines often have poor contrast against dark backgrounds anyway, a custom, high-contrast focus ring (e.g., `focus-visible:ring-2 focus-visible:ring-white/30`) is critical for keyboard users.
**Action:** Always pair `focus:outline-none` with a custom `focus-visible` state (like `focus-visible:ring-2 focus-visible:ring-white/30 focus-visible:ring-offset-1 focus-visible:ring-offset-black`) when creating interactive elements to ensure they remain accessible without compromising visual design.
